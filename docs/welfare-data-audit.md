## 本次發現的關鍵風險

115年度「原住民族長者裝置假牙補助」原本公告實施至115年10月31日，但因經費趨近用罄，官方後續公告自115年7月30日起停止受理。這表示系統不能只記錄原始計畫期限，還必須追蹤後續的異動、延期、經費用罄與停止受理公告。

## 資料使用原則

1. 介面必須同時顯示官方來源、最後查核日與受理狀態。
2. 年度型或有預算上限的福利，不可單純標示為「可申請」。
3. 金額、期限、所得與財產門檻屬於高變動欄位，上線前及定期更新時必須重新核對。
4. 系統只能提供初步導引，不得顯示「你一定符合」或代替政府核定。
5. 未確認或已過期的資料，應先引導使用者聯絡承辦單位，不提供送件指示。

## 前台串接狀態

已完成串接。`data/welfare-benefits.json` 是唯一需要維護的原始資料，執行 `node tools/build-welfare-data.mjs` 後會產生 `dist/welfare-data.js`，前台的「找福利」與「申請準備」都會使用這 8 筆資料。

前台目前會：

1. 依經濟生活、就醫照顧與交通外出分類福利。
2. 顯示適用對象、步驟、文件、承辦單位、查核日與官方來源。
3. 對超過 90 天未查核的資料顯示提醒。
4. 對需確認申請期間的項目要求先洽官方窗口。
5. 對已停止受理的項目停止送件引導，改為顯示公告與真人協助。

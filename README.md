# 福利行動導航 LINE Bot 介面模擬

這是純 HTML、CSS、JavaScript 網站。用 VS Code 開啟 `dist` 資料夾後，在 Mac 終端機執行 `open index.html` 即可預覽；不需要 `npm run dev`。

手機畫面右上角可切換中文、阿美語、泰雅語。切換時會重新開始示範對話。現在只有下列招呼語已查核來源，其餘操作與福利說明保留中文輔助，避免未經校對的翻譯造成申請誤解：

- 海岸阿美語：`Nga’ay ho!`
- 賽考利克泰雅語：`lokah su!`

招呼語來源：[族語 E 樂園〈生活常用語〉](https://web.klokah.tw/lifesentences/)。正式用於桃園市原住民集會所前，仍需請當地使用者或族語教師確認語別、拼寫及完整介面文案。

本網站沒有真實福利資料，也沒有連接 LINE 官方帳號或處理個人資料。
